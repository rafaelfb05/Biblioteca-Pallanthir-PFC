# BIBLIOTECA PALLANTHIR
Um sistema de biblioteca criado para ajudar estudantes de diversas áreas.
Os usuários podem avaliar os livros lidos, 
e os livros com melhor avaliação são mais recomendados,
ajudando alunos novos a encontrar mais facilmente as melhores opções para estudo.
Também existe uma aba de favoritos para o estudante salvar os livros que mais gostar 
O sistema não oferece os livros digitalmente, apenas reservas e compras para buscar em uma biblioteca física.



## TECNOLOGIAS UTILIZADAS
Java: É uma linguagem de programação usada para o Back-end, oferece recursos adequados para o desenvolvimento de aplicações robustas, escaláveis e orientadas a objetos.

Spring Boot: É um framework usado para desenvolvimento de aplicações Java ele fornece uma infraestrutura para criação de aplicações web e APIs facilitando a organização do projeto, além de oferecer diversas dependências que ajudam muito no desenvolvimento do projeto.

Html: É uma linguagem de marcação usada para o Front-end, ele funciona como uma espécie de esqueleto para o site.

CSS: Mais uma linguagem para o Front-end, porém essa serve para definir a aparência visual e estilo das páginas web escritas em Html.

JavaScript: Também uma linguagem de programação para Front-end, porém essa é a que adiciona dinamismo, interatividade e inteligência a páginas da web, controlando as ações e os comportamentos dos objetos na tela.

React: É uma biblioteca JavaScript feita para o Front-end e trabalha com uma arquitetura baseada em componentes reutilizáveis, permitindo dividir a interface em partes independentes.

PostgreSQL: É um sistema gerenciador de banco de dados relacional responsável pela persistência das informações da aplicação, permitindo armazenar e manipular dados.

Google Books API: API externa utilizada para obter informações dos livros que serão adicionados ao sistema.

Mercado Pago API: Utilizado para integrar o sistema ao serviço de pagamentos em compras ou aluguéis de livros.

Spring Security: Utilizado para implementar os mecanismos de autenticação e autorização da aplicação, será responsável por auxiliar a implementar a segurança no sistema.

JWT (Json Web Token): Tecnologia utilizada para auxiliar no processo de autenticação e autorização dos usuários, permitindo a transmissão segura de informações relacionadas à sessão e à identidade do usuário.

BCrypt: Algoritmo utilizado para gerar hashes das senhas dos usuários, permitindo armazená-las de forma mais segura no banco de dados.

Vercel: Será utilizada para realizar a hospedagem e disponibilização do front-end.

Render: Utilizado para hospedar o back-end desenvolvido em Java com Spring Boot.

Supabase: Será utilizado para hospedar o banco de dados PostgreSQL.
